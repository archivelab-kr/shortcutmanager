# shortcutmanager-web

ShortcutManager 웹사이트(GitHub Pages, 원격 `archivelab-kr/shortcutmanager`, 주소 https://archivelab-kr.github.io/shortcutmanager/).

- 문구는 모두 `build.py`의 `TEXT`에 있습니다(영어 · 한국어). 고친 뒤 `python3 build.py`로 페이지를 다시 만들고, 만들어진 HTML도 함께 커밋합니다.
- `assets/`의 영상과 그림은 `../shortcutmanager-store-assets/`의 것을 옮긴 것입니다(실제 앱을 찍은 것).
- **push하면 바로 공개됩니다.** 처리방침은 2.0.0 기준이므로 2.0.0이 배포될 때까지 push하지 않습니다.
- 커밋은 `[웹] 요약` 형식입니다.
